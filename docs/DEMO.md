# Demo script (2:30)

Record the screen at 1280×800, light theme, browser zoom 100%. Judges can also try the app themselves, so the video only needs to show the moments that matter. Open the app fresh in a private window so the stand-up set is loaded.

## 0:00 – The problem (15s)
Say: "Every comic has made a reference that died. The reference was fine; the room was wrong. Callback tells you before you walk on stage."
Show: the app with the stand-up set already underlined.

## 0:15 – One room (35s)
- Point at the underlines: "Atlanta. Waffle House, Outkast and P-Valley are green. Tom Brady and Wawa are red."
- Switch **City** to **Boston** and watch it flip: "Same set, Boston. Dunkin' lands, Waffle House dies. Qloo knows what each city over-indexes on."
- Switch back to Atlanta.

## 0:50 – Why (30s)
- Click **Tom Brady**. "Click any underline to see why: Atlanta is #4 of 8 cities for him. Boston's #1."
- Point at the **city bars** and the **age** line.
- Under the editor, open the **Scored with Qloo** receipt: "Everything here comes from Qloo: search, then insights with signal.location across eight cities, then age demographics."

## 1:20 – Fix my set (35s)
- Click **Fix my set**. Let the steps stream.
- Read one: "It picked Justin Fields for Tom Brady because the joke is about a guy who throws, so it needs a quarterback, not a running back. It only rewrote that sentence."
- Click **Undo**, to show nothing is destructive.

## 1:55 – Tour mode (20s)
- Click **Tour**, add **Denver** and **Houston**.
- "A comic on tour sees what holds everywhere and what to swap in each city."

## 2:15 – Inside your agent (15s)
- Cut to Claude with the Callback connector: "Will this set work in Houston? Fix whatever dies."
- "Callback is also an MCP server, so any agent can use Qloo's taste data through it."
- End on the logo: "Callback. A spell-checker for cultural references."

## Before recording
- [ ] Open the live URL; confirm the stand-up set shows 3 green, 2 red, 2 yellow in Atlanta.
- [ ] Run **Fix my set** once to warm the model (and check Groq quota).
- [ ] Add the connector in Claude and run the Houston prompt once, so the video shows a clean take.
